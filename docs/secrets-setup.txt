여행 DB Codespaces Secrets 복사 및 설정 안내

GitHub 저장소 → Settings → Secrets and variables → Codespaces → New repository secret
아래 두 Secret을 각각 등록하세요. Name과 Secret 칸은 서로 다릅니다.

첫 번째 Secret
Name 칸에 넣을 내용:
TRAVEL_SPREADSHEET_ID

Secret 칸에 넣을 내용:
본인 마스터 Google Sheets URL의 /d/와 /edit 사이에 있는 파일 ID를 복사하세요.
예: https://docs.google.com/spreadsheets/d/<본인_마스터_ID>/edit
<본인_마스터_ID>라는 예시 문자를 그대로 Secret에 넣지 마세요.

두 번째 Secret
Name 칸에 넣을 내용:
GOOGLE_SERVICE_ACCOUNT_JSON

Secret 칸에 넣을 내용:
Google Cloud에서 다운로드한 서비스 계정 JSON 파일의 내용 전체.
이 문장 자체를 Secret 값으로 넣지 마세요. 실제 JSON 키는 이 문서에 포함되어 있지 않습니다.

JSON 파일을 복사하는 방법
본인 컴퓨터에서 다운로드한 JSON 파일을 메모장 또는 텍스트 편집기로 여세요.
Windows/Linux: Ctrl+A → Ctrl+C. macOS: Command+A → Command+C.
GitHub의 Secret 칸에 붙여 넣으세요. JSON의 여는 중괄호부터 닫는 중괄호까지 전체를 그대로 넣습니다.
파일 이름이나 파일 경로가 아니라 파일 내용 전체가 필요합니다.
실제 키 내용은 채팅, 공유 문서, 저장소에 붙이지 말고 GitHub Codespaces Secret에 직접 넣으세요.

권한 설정
JSON 파일의 client_email 값을 확인하세요.
본인 마스터 시트의 공유 버튼에서 해당 이메일을 편집자로 추가하세요.
Google Cloud 프로젝트에서 Google Sheets API도 사용 설정해야 합니다.

마무리
두 Secret을 저장한 뒤 Codespace를 중지하고 다시 시작하세요.
완료 후 채팅에 '설정 완료'라고 알려주면 실제 연결을 확인합니다.
